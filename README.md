## BIM & Modeling

### IFC & OpenBIM
- [IfcOpenShell](https://github.com/IfcOpenShell/IfcOpenShell) — Read/write IFC files in Python
- [xBIM Toolkit](https://github.com/xBimTeam/XbimEssentials) — .NET SDK for IFC
- [BIMserver](https://github.com/opensourceBIM/BIMserver) — Open source BIM server
- [BlenderBIM](https://github.com/IfcOpenShell/IfcOpenShell/tree/v0.8.0/src/blenderbim) — OpenBIM addon for Blender
- [IFC.js](https://github.com/IFCjs/web-ifc) — IFC parser for the browser
- [Speckle](https://github.com/specklesystems) — Open data platform for AEC
- [IfcPatch](https://github.com/IfcOpenShell/IfcOpenShell/tree/v0.8.0/src/ifcpatch) — Automated IFC file modification
- [IFCdiff](https://github.com/IfcOpenShell/IfcOpenShell/tree/v0.8.0/src/ifcdiff) — Compare IFC models

### Revit & Dynamo
- [pyRevit](https://github.com/eirannejad/pyRevit) — Python framework for Revit
- [Clockwork for Dynamo](https://github.com/andydandy74/ClockworkForDynamo) — Utility node package
- [archi-lab](https://github.com/ksobon/archilab) — Dynamo nodes for Revit
- [Rhythm](https://github.com/johnpierson/RhythmForDynamo) — Dynamo package by John Pierson
- [BakeryForDynamo](https://github.com/LukeyJohnson/BakeryForDynamo) — Documentation tools

### Parametric & Other
- [FreeCAD](https://github.com/FreeCAD/FreeCAD) — Open source parametric 3D modeler
- [OpenSCAD](https://github.com/openscad/openscad) — Script-based 3D modeling
- [Ladybug Tools](https://github.com/ladybug-tools) — Environmental design analysis

## AI & Document Processing

### Frameworks
- [LangChain](https://github.com/langchain-ai/langchain) — LLM application framework
- [LlamaIndex](https://github.com/run-llama/llama_index) — RAG framework for structured data
- [CrewAI](https://github.com/crewAIInc/crewAI) — Multi-agent orchestration

### Document Extraction
- [Unstructured](https://github.com/Unstructured-IO/unstructured) — Extract data from PDFs/docs
- [Marker](https://github.com/VikParuchuri/marker) — PDF to Markdown converter
- [Docling](https://github.com/DS4SD/docling) — IBM document extraction
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) — OCR for scanned plans
- [Layout Parser](https://github.com/Layout-Parser/layout-parser) — Document layout detection
- [Surya](https://github.com/VikParuchuri/surya) — OCR + layout + table detection

### Automation
- [n8n](https://github.com/n8n-io/n8n) — Workflow automation (self-hosted)
- [Activepieces](https://github.com/activepieces/activepieces) — Open source Zapier alternative
- [Huginn](https://github.com/huginn/huginn) — Self-hosted automation agents
